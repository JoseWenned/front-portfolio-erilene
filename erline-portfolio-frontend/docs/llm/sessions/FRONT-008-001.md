# FRONT-008-001 — Implementação da seção Experiência

## Identificação

* **Feature:** FRONT-008
* **Descrição:** Implementação da seção Experiência
* **Tipo:** Desenvolvimento de feature
* **Frontend:** Next.js + React + TypeScript
* **Estilização:** SCSS Modules
* **Testes:** Vitest + React Testing Library

## Objetivo

Implementar a seção de experiência profissional da Erline, mantendo o padrão arquitetural, visual e de qualidade estabelecido nas features anteriores.

## Atividades realizadas

* Criação da feature `Experiencia`.
* Criação do componente `Experiencia.feature.tsx`.
* Criação dos estilos em `experiencia.module.scss`.
* Criação dos testes automatizados.
* Utilização dos fragments `Section` e `Container`.
* Estruturação dos dados através de uma coleção.
* Implementação de cards para apresentação das experiências.
* Implementação de responsividade.
* Integração da seção na página principal.

## Estrutura criada

```text
src/features/Experiencia/
├── Experiencia.feature.tsx

└── Experiencia.test.tsx
```

## Decisões técnicas

### Organização por feature

A seção foi criada em:

```text
src/features/Experiencia/
```

mantendo o isolamento do conteúdo específico da seção.

### Reutilização

Foram reutilizados os fragments:

```tsx
<Section />
<Container />
```

evitando duplicação de responsabilidades já existentes no Design System.

### Coleção de experiências

As experiências são representadas através de:

```ts
const experiences = [...]
```

Essa estrutura permite adicionar novas experiências futuramente sem modificar a lógica principal de renderização.

### Dados provisórios

Como os dados profissionais detalhados da Erline ainda não foram definidos, foram utilizados somente dados genéricos.

Não foram inventados nomes de academias, empresas, períodos ou cargos anteriores.
