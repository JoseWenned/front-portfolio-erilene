# FRONT-007-001 — Implementação da seção Formação

## Identificação

* **Feature:** FRONT-007
* **Descrição:** Implementação da seção Formação
* **Tipo:** Desenvolvimento de feature
* **Arquitetura:** Componentização por feature
* **Frontend:** Next.js + React + TypeScript
* **Estilização:** SCSS Modules
* **Testes:** Vitest + React Testing Library

## Objetivo

Implementar a seção de formação acadêmica do portfólio da Erline, mantendo o padrão arquitetural e visual estabelecido nas features anteriores.

## Atividades realizadas

* Criação da feature `Formacao`.
* Criação do componente `Formacao.feature.tsx`.
* Criação dos estilos em `formacao.module.scss`.
* Criação dos testes automatizados.
* Utilização dos fragments `Section` e `Container`.
* Implementação de apresentação em formato de timeline.
* Implementação de responsividade.
* Integração da seção na página principal.

## Decisões técnicas

### Organização por feature

A seção foi mantida dentro de:

```text
src/features/Formacao/
```

Isso mantém o conteúdo específico da página isolado e facilita a evolução independente da feature.

### Reutilização do Design System

Foram utilizados:

```tsx
<Section />
<Container />
```

em vez de reproduzir suas responsabilidades dentro da feature.

### Dados como coleção

A formação foi representada por uma coleção:

```ts
const formations = [...]
```

Essa decisão permite adicionar novas formações posteriormente sem alterar a estrutura de renderização.

### Timeline

Foi utilizada uma implementação baseada exclusivamente em CSS para representar visualmente a sequência das formações.

Isso evita adicionar uma dependência externa para uma necessidade simples.

### Dados profissionais

Não foram adicionados dados específicos como instituição ou período sem confirmação.

A implementação inicial utiliza apenas informações profissionais conhecidas e genéricas.
