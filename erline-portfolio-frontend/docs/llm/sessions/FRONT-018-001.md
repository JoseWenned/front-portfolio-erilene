# FRONT-013-001 — Core Domain

## Contexto

A FRONT-013 tem como objetivo integrar o frontend do portfólio com a API REST desenvolvida em Spring Boot.

A arquitetura existente mantém as features responsáveis pela apresentação e interação com o usuário. Para evitar que essas features dependam diretamente de detalhes de HTTP, foi definida uma camada `core` contendo Domain, Application e Infrastructure.

## Objetivo da sessão

Implementar a primeira etapa da FRONT-013:

* entidade `Depoimento`;
* status do depoimento;
* contrato do repositório;
* documentação arquitetural;
* testes do domínio.

## Contrato utilizado

A implementação foi baseada no contrato real da API backend.

### Criação

```http
POST /api/depoimentos
```

Payload:

```json
{
  "nome": "Nome do cliente",
  "comentario": "Comentário do cliente",
  "nota": 5,
  "fotoUrl": "https://exemplo.com/foto.jpg"
}
```

### Listagem

```http
GET /api/depoimentos
```

Retorno:

```json
[
  {
    "id": "uuid",
    "nome": "Nome do cliente",
    "comentario": "Comentário do cliente",
    "nota": 5,
    "fotoUrl": "https://exemplo.com/foto.jpg",
    "status": "APROVADO",
    "createdAt": "2026-09-14T12:00:00",
    "updatedAt": "2026-09-14T12:00:00"
  }
]
```

## Decisões arquiteturais

### Entidade

A entidade `Depoimento` representa o modelo utilizado pelo frontend.

O UUID utilizado pelo backend é representado como `string`, pois é dessa forma que o identificador chega através do JSON.

`LocalDateTime` é representado como `string`, pois a API fornece a data em formato textual.

### Repository

O contrato do repositório pertence ao domínio.

A implementação concreta será criada posteriormente na infraestrutura.

Isso impede que o domínio tenha conhecimento de `fetch`, URLs ou detalhes do protocolo HTTP.

## Fluxo arquitetural

```text
Feature
   ↓

   ↓
DepoimentoRepository
   ↑
DepoimentoApiRepository
   ↓

```

## Fora do escopo

Esta sessão não implementa:

* chamadas HTTP;
* `fetch`;
* DTOs de infraestrutura;
* use cases;
* integração com React;
* autenticação;
* operações administrativas;
* aprovação ou rejeição de depoimentos.
