# FRONT-014-001 — Testes de Integração

## 1. Contexto

Esta sessão teve como objetivo implementar e validar os testes de integração do fluxo de contato do portfólio da Erline.

A funcionalidade de contato utiliza uma API Route do Next.js responsável por receber os dados do formulário e realizar o envio através do Resend.

Os testes unitários já validavam o comportamento da Route Handler utilizando mocks.

O objetivo desta etapa foi adicionar uma validação utilizando o serviço real.

---

## 2. Objetivos

- Criar um teste de integração para a API Route de contato.
- Utilizar o Resend real durante a execução do teste.
- Configurar o carregamento das variáveis de ambiente.
- Separar os testes unitários dos testes de integração.
- Validar o retorno real da API.
- Confirmar que o fluxo de envio funciona fora do ambiente de mocks.

---

## 3. Decisões técnicas
