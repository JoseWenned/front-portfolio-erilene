# FRONT-010-001 — Implementação da seção de Galeria

## Identificação

* **Feature:** FRONT-010
* **Nome:** Galeria
* **Tipo:** Feature de apresentação
* **Frontend:** Next.js / React / TypeScript
* **Estilização:** SCSS Modules
* **Imagens:** Next/Image
* **Testes:** Vitest + React Testing Library

## Objetivo

Implementar a seção de Galeria do portfólio profissional da Erline, criando uma estrutura reutilizável para apresentação de imagens relacionadas à sua atuação profissional.

## Atividades realizadas

Foram realizadas as seguintes atividades:

* criação da feature `Galeria`;
* criação do componente `Galeria.feature.tsx`;
* criação do stylesheet `galeria.module.scss`;
* criação dos testes automatizados;
* utilização dos fragments `Container` e `Section`;
* utilização do componente `next/image`;
* criação da coleção local de imagens;
* implementação de grid responsivo;
* definição de proporção consistente para as imagens;
* implementação de interações visuais;
* integração da Galeria na página principal;
* validação com testes, lint e build;
* documentação técnica da feature.

## Decisões técnicas

Foi utilizada uma coleção local contendo:

```ts
const gallery = [
  {
    src,
    alt,
    title,
  },
];
```

A estrutura permite adicionar novas imagens sem modificar a estrutura principal do componente.

O componente `next/image` foi escolhido para aproveitar os recursos de otimização de imagens do Next.js.

Foi utilizado `fill` em conjunto com um container de posição relativa e `aspect-ratio`, garantindo controle sobre o espaço ocupado pelas imagens.
