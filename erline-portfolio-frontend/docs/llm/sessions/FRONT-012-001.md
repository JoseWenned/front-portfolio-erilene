# FRONT-012-001 — Implementação da seção de contato

## Contexto

A seção de contato faz parte do portfólio profissional de Erline e tem como objetivo permitir que visitantes interessados em seus serviços entrem em contato.

Inicialmente foi considerada apenas a implementação visual do formulário.

Durante a definição da funcionalidade, foi identificada a necessidade de estabelecer previamente uma arquitetura para o envio real das mensagens.

## Decisão

Foi decidido utilizar o Resend como serviço externo de envio de e-mails.

O backend Spring Boot existente no projeto não será utilizado para essa funcionalidade.

A solução utilizará uma API Route do Next.js como camada intermediária entre o formulário e o Resend.

## Arquitetura definida

```text
Frontend
   │
   │ dados do formulário
   ▼
Next.js API Route
   │
   │ API Key protegida
   ▼
Resend API
   │
   ▼
E-mail da Erline
