# FRONT-009-001 — Implementação da seção de Certificações

## Identificação

* **Feature:** FRONT-009
* **Nome:** Certificações
* **Tipo:** Feature de apresentação
* **Frontend:** Next.js / React / TypeScript
* **Estilização:** SCSS Modules
* **Testes:** Vitest + React Testing Library

## Objetivo

Implementar a seção de Certificações do portfólio profissional da Erline, mantendo o padrão visual, arquitetural e de testes estabelecido nas features anteriores.

## Atividades realizadas

Foram realizadas as seguintes atividades:

* criação da feature `Certificacoes`;
* criação do componente `Certificacoes.feature.tsx`;
* criação do stylesheet `certificacoes.module.scss`;
* criação dos testes automatizados;
* utilização dos fragments `Container` e `Section`;
* criação da coleção inicial de certificações;
* implementação do layout responsivo;
* integração da feature na página principal;
* validação de testes, lint e build;
* documentação técnica da feature.

## Decisões técnicas

A seção foi implementada utilizando uma coleção local de objetos:

```ts
const certifications = [
  {
    title: "...",
    description: "...",
  },
];
```

A decisão permite que novas certificações sejam adicionadas posteriormente sem alterar a estrutura de apresentação.

Também foi decidido não inventar certificações reais da profissional. Os dados atuais possuem caráter provisório e deverão ser substituídos quando as informações oficiais forem disponibilizadas.
