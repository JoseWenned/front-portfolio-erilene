# FRONT-011-001 — Implementação da seção de Depoimentos

## 1. Identificação

**Feature:** FRONT-011
**Nome:** Depoimentos
**Tipo:** Desenvolvimento de interface
**Status:** Implementado

---

## 2. Objetivo

Implementar a seção de depoimentos do portfólio da Erline.

A funcionalidade deveria permitir:

* apresentar depoimentos;
* apresentar nome e texto dos clientes;
* disponibilizar formulário para novos depoimentos;
* manter a interface preparada para futura integração com o backend.

---

## 3. Atividades realizadas

Durante a implementação foram desenvolvidos:

* componente `Depoimentos.feature.tsx`;
* estilos com CSS Modules;
* lista inicial de depoimentos mockados;
* formulário de envio;
* campos de nome e depoimento;
* botão de envio;
* layout responsivo;
* estrutura semântica;
* testes automatizados;
* integração da feature com a página principal.

---

---

## 5. Decisões técnicas

### Dados locais inicialmente

Os depoimentos foram mantidos como dados locais temporários.

Isso permite desenvolver e validar a interface sem introduzir dependência da API antes da etapa planejada.

### Integração posterior

A comunicação com o backend será realizada em:

```text
FRONT-013 — Integração API
```

### Separação entre UI e infraestrutura

A feature não realiza requisições HTTP nesta etapa.

Essa decisão evita acoplamento prematuro entre a camada de apresentação e a infraestrutura de comunicação.

### Formulário inicialmente visual

O formulário possui estrutura visual e semântica, mas ainda não possui comportamento de envio.

A implementação do fluxo real será realizada durante a integração com o backend.

## 6. Acessibilidade

Foram utilizadas queries semânticas nos testes, incluindo:


Os campos do formulário possuem labels associados.

Os depoimentos utilizam `blockquote` para representar semanticamente os relatos.
