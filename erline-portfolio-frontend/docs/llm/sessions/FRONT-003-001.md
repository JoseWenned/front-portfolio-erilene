# FRONT-003-001 — Desenvolvimento do Layout Global

## Objetivo

Implementar a estrutura global de layout do frontend do portfólio da Erline.

## Atividades

- Desenvolvimento do Header;
- Desenvolvimento do Footer;
- Implementação da navegação principal;
- Implementação dos links sociais;
- Aplicação de responsividade inicial;
- Integração com o componente Container;
- Composição do RootLayout;
- Atualização do teste da página inicial;
- Criação dos testes do Header;
- Criação dos testes do Footer.

## Decisões

Header e Footer foram definidos como componentes de layout global.
