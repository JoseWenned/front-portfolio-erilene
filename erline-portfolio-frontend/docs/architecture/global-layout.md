# Global Layout

## Objetivo

Definir a estrutura global de layout do frontend do portfólio da Erline,
garantindo uma organização consistente entre Header, conteúdo principal e Footer.

## Estrutura

A aplicação utiliza o `RootLayout` do Next.js para compor os elementos
globais da interface:

```text
RootLayout
├── Header
├── main
│   └── page content
└── Footer
